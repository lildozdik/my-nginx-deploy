# my-nginx-deploy

Простой pet-проект по автоматизации развёртывания nginx-сервера с помощью Bash-скрипта.

## Что делает проект

- Устанавливает и настраивает nginx на Ubuntu Server
- Разворачивает кастомную конфигурацию и главную страницу
- Автоматизирует полный цикл деплоя одной командой

## Структура репозитория

- `deploy.sh` — скрипт автоматического деплоя (установка nginx, копирование конфигурации, перезапуск сервиса)
- `nginx.conf` — конфигурация nginx
- `index.html` — главная страница сайта

## Как запустить

```bash
chmod +x deploy.sh
./deploy.sh
```

После выполнения сайт будет доступен по адресу `http://localhost`.
